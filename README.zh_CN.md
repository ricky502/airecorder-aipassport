# AI Passport 灵感记忆卡

[English](README.md)

这是把 FoloToy AI Passport 改造成“离线优先的灵感录音卡”的固件与本地接收端。它通过实体按键录下灵感，音频在收到接收端确认前始终保留；整段录音完成后，再交给使用者自行配置的 AI 或协作工具流程。

## 已实现功能

- **实体按键录音：** `OK` 开始、暂停、继续；`DOWN` 停止并封存当前录音。
- **离线优先：** 8 kHz 单声道 IMA-ADPCM 压缩，已验证的剩余 voicefs 空间可保存约 12 分钟录音。
- **滚动上传：** 每 60 秒封存一个分片；仅在有待传录音时打开 Wi-Fi；服务端 HTTP 确认成功后才删除本地文件。
- **本地收件箱：** `UP` 打开未上传录音列表；可选择、试听、调节播放音量，长按 `OK` 进入删除确认。
- **播放器：** 显示真实的已播放/总时长与进度条；音量使用独立百分比显示。
- **待机主屏：** 日期、时间、电量、短音量波形，以及随昼夜变化的 12 帧打坐小和尚插画。
- **省电：** 录音或暂停时屏幕维持约 18% 背光，状态可见但不浪费电；空闲后依次降亮、关背光、轻睡眠。

## 整体设计

```text
实体按键
  -> 录音状态机 -> ADPCM 分片文件 -> 可恢复上传队列
                                      -> 短暂 Wi-Fi 上传窗口
                                      -> 使用者配置的接收端
                                             -> ASR / AI / 协作工具
```

设备不把 Wi-Fi 密码、个人局域网地址、飞书群 ID 或 AI 密钥写进固件源码。配网页面的接收地址可以留空：接收端启动时通过 mDNS 广播自己的服务，卡片在同一 Wi-Fi 下自动发现并记住该电脑的持久标识，因此电脑换 DHCP 地址也不影响同步。也仍可手动填写地址作为兼容方式；接收端的外部服务凭据仅从部署者自己的环境变量读取。

## 按键说明

| 场景 | `OK` | `UP` | `DOWN` |
| --- | --- | --- | --- |
| 首页 | 录音 / 暂停 / 继续 | 打开离线列表 | 停止并发送 |
| 列表 | 播放 / 停止 | 上一条 | 下一条 |
| 播放中 | 停止 | 音量增加 | 音量减少 |
| 删除确认 | 确认 | 上下选择 | 上下选择 |

列表中长按 `OK` 进入删除确认；长按 `UP` 回到首页。首页长按 `UP` 打开本地 Wi-Fi 与接收地址配置页。

## 接收端与 AI

`backend/server.py` 接收按顺序上传的 ADPCM 分片，录音完成后重建为 WAV，并调用可配置的后处理流程。它不包含任何凭据；请在自己的部署环境中通过环境变量配置转写服务、AI 服务与协作工具的发送目标。说明见 [backend/README.zh_CN.md](backend/README.zh_CN.md)。

## 发布与安全边界

- 只刷写 `0x10000` 开始的应用分区，不要整片擦除设备。
- 固件避开原厂身份和资源区。
- 不提交 `.env`、录音文件、接收端数据、设备日志或包含配置二维码的截图。
- 新刷设备可以立即离线录音；填写自己的接收地址后才会上传。

## 构建

使用 ESP-IDF 5.5 或兼容环境：

idf.py build
